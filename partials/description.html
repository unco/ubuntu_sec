A use-after-free in the Linux kernel's IPv4 TCP connection handling can lead to remote code execution. IP options can be handed to a child socket while a concurrent retransmitted SYN is still reading them, and because TCP child sockets are freed without RCU deferral the options can be read after they are freed. Request socket migration has a similar flaw. The fix moves the affected destructors to kfree_rcu(). IPv6 is not affected by the first issue.
